# Ryan 的知识库

> 本地优先的 Obsidian 知识库，全部是 Markdown 纯文本，数据在你自己手里。
> 创建：2026-11-16｜结构：PARA

## 怎么用

1. 在 Obsidian 里选 `Open folder as vault`，打开这个文件夹 `notes/`。
2. 有想法先丢进 [[00-Inbox]]，不用想放哪。
3. 每周整理一次：Inbox 里的东西归到 Projects / Areas / Resources，写完的移到 Archive。
4. 以后想找什么，直接跟我说，比如“帮我在知识库里找偏印”，我来搜。

## 入口

- [[00-Inbox]] — 待整理
- [[Daily/2026-11-16]] — 今天
- [[03-Resources/八字/八字格局总览]] — 八字
- [[03-Resources/八字/偏印]] — 偏印：出路与局限

## 结构

| 文件夹 | 放什么 |
| --- | --- |
| `00-Inbox` | 随手记、灵感、未分类 |
| `01-Projects` | 有截止日期的事，一个项目一个文件夹 |
| `02-Areas` | 长期负责的事，如健康、财务、学习 |
| `03-Resources` | 可复用的知识，如八字、方法论、收藏 |
| `04-Archive` | 做完、过期的东西 |
| `Daily/` | 每日笔记 |
| `Templates/` | 笔记模板 |

## 约定

- 一个想法一个文件，标题就是问题。
- 用 `[[双向链接]]` 连起来，不用死记文件夹。
- 每条笔记开头写一句话摘要，结尾写来源。
- 标签用 `#标签`，如 `#八字` `#偏印`。
