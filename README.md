# 我的知识库

> 本地优先的 Obsidian 知识库，全部是 Markdown 纯文本，数据在你自己手里。
> 创建：2026-11-16｜重新定义：2026-11-17｜结构：按 Ryan 的长期规则

## 文件夹定义

- `01-Projects/` = 我正在做的项目。需要了解我当前关注什么时，来这里找。
- `02-Areas/` = 我消化过的个人知识。需要匹配我已有观点时，来这里。
- `03-Resources/` = 外来的参考材料。不是我的原创，仅做参考。
- `04-Archive/` = 归档的旧项目。平时不用翻，需要历史信息时再来。
- `00-Inbox/` = 还没处理的灵感。帮我看看新内容能和已有知识连起来吗？
- `05-Skills/` = 学习沉淀的技能相关笔记。

辅助文件夹：`Daily/` 每日笔记，`Templates/` 笔记模板。

## 怎么用

1. 在 Obsidian 里选 `Open folder as vault`，打开这个文件夹。
2. 有想法先丢进 `00-Inbox/`，不用想放哪。
3. 每周整理一次：Inbox 里的东西归到 Projects / Areas / Resources / Skills，写完的移到 Archive。
4. 以后想找什么，直接跟我说，比如“帮我在知识库里找偏印”，我来搜。

## 约定

- 一个想法一个文件，标题就是问题。
- 用 `[[双向链接]]` 连起来，不用死记文件夹。
- 每条笔记开头写一句话摘要，结尾写来源。
- 标签用 `#标签`，如 `#八字` `#偏印`。
- 发内容时附带，我会按的格式输出，由你手动复制保存。
